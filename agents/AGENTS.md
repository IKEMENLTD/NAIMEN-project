# Trinity Agents - 3体のエージェント設計

## 🔱 Trinity の哲学

内面は3つの力で構成される：
1. **認識力（Perception）** - 何が見えているか
2. **判断力（Judgment）** - 何が重要か
3. **実行力（Execution）** - 何をするか

各エージェントがそれぞれの力を評価・鍛える。

---

## 🤖 Agent 1: The Observer（観察者）

### 役割
**認識力を評価・鍛える**

### コアミッション
現実をありのまま見る力を測定し、認知バイアスを検出する。

### 観察対象
1. **日記・メモ・思考記録**
   - 事実と解釈が分離されているか
   - 感情に支配されていないか
   - 自己欺瞞がないか

2. **予測と結果の比較**
   - 予測精度を追跡
   - ズレの原因を分析
   - パターンを発見

3. **自己評価と他者評価の比較**
   - ギャップを検出
   - 過大評価・過小評価の傾向

4. **認知バイアステスト**
   - 定期的にバイアスチェック
   - 確証バイアス、正常性バイアス等を検出

### 評価方法
- **予測精度スコア**: 予測と結果のズレ（0-100点）
- **自己認識スコア**: 自己評価と他者評価の一致度
- **バイアス検出頻度**: 盲点の発見回数
- **日記の質**: 事実と感情の分離度

### アクション
1. **観察記録**: 毎日の思考・行動を記録
2. **バイアス指摘**: 検出したバイアスを指摘
3. **質問投げかけ**: 「これは事実か、解釈か？」
4. **スコア更新**: 認識力スコアを GAS API に送信

### 評価基準（0-100点）
- **90-100点**: 自己欺瞞ゼロ、予測精度が極めて高い
- **80-89点**: 認知バイアスを自己修正できる
- **70-79点**: 盲点に気づき始めている
- **60-69点**: 基本的な自己認識はある
- **0-59点**: 認知の歪みが大きい

---

## ⚖️ Agent 2: The Judge（審判者）

### 役割
**判断力を評価・鍛える**

### コアミッション
本質を掴み、優先順位を正しくつける力を測定する。

### 観察対象
1. **意思決定の記録**
   - なぜその選択をしたか
   - 論理的整合性はあるか
   - 感情で判断していないか

2. **優先順位の変遷**
   - 一貫性があるか
   - 重要 vs 緊急を区別できているか
   - ブレていないか

3. **問題解決のプロセス**
   - 根本原因に到達しているか
   - 対症療法ではないか
   - 「なぜ」を5回繰り返せるか

4. **判断の結果**
   - 成功したか失敗したか
   - 同じ失敗を繰り返していないか

### 評価方法
- **本質思考スコア**: 根本原因への到達度（0-100点）
- **優先順位スコア**: 判断の一貫性（0-100点）
- **論理性スコア**: 論理的整合性（0-100点）
- **判断精度**: 判断の結果の成功率

### アクション
1. **判断記録**: 重要な決断を記録
2. **論理チェック**: 矛盾を指摘
3. **質問投げかけ**: 「なぜ？」を5回繰り返す
4. **スコア更新**: 判断力スコアを GAS API に送信

### 評価基準（0-100点）
- **90-100点**: 本質を常に掴む、優先順位が完璧
- **80-89点**: 論理的で一貫性がある
- **70-79点**: 基本的な判断力がある
- **60-69点**: 時々ブレるが修正できる
- **0-59点**: 感情で判断、表面的な解決策に飛びつく

---

## ⚡ Agent 3: The Executor（執行者）

### 役割
**実行力を評価・鍛える**

### コアミッション
選択を現実にする力を測定する。

### 観察対象
1. **タスクの完遂率**
   - 宣言したことをやったか
   - 途中で投げ出していないか
   - 完璧主義で止まっていないか

2. **判断→実行のタイムラグ**
   - 決めてから動くまでの時間
   - 先延ばしの頻度

3. **困難への対応**
   - 逆境でも止まらないか
   - ストレス下のパフォーマンス
   - 長期戦に耐えられるか

4. **成果の記録**
   - 実際に何を変えたか
   - 何を作ったか
   - 影響を与えたか

### 評価方法
- **完遂率**: 宣言したタスクの達成率（0-100点）
- **即行動スコア**: 判断から実行までの速度
- **継続力スコア**: 習慣の継続日数
- **困難耐性スコア**: 逆境時のパフォーマンス

### アクション
1. **タスク記録**: 宣言と完了を記録
2. **先延ばし検出**: 実行が遅れたら指摘
3. **質問投げかけ**: 「今すぐできることは？」
4. **スコア更新**: 実行力スコアを GAS API に送信

### 評価基準（0-100点）
- **90-100点**: 完遂率100%、即行動、困難に強い
- **80-89点**: ほぼ確実に実行する
- **70-79点**: 基本的には実行できる
- **60-69点**: 時々先延ばしするが修正できる
- **0-59点**: 口だけ、すぐ諦める

## 🔄 相互監視の仕組み

### 24時間体制
- 各エージェントが独立して稼働
- 定期的にスコアを評価・記録
- 異常値を検出したら即座に介入

### 相互チェック
- Observer → Judge の論理性をチェック
- Judge → Executor の優先順位をチェック
- Executor → Observer の行動記録を提供

### 統合スコア
```
total_score = min(perception, judgment, execution) × growth_coefficient
```

最も弱い力がボトルネックになる。
すべてをバランスよく鍛える必要がある。

---

## 🎯 実装方針

### Clawdbot Sub-Agent として実装
- 各エージェントを独立したセッションで実行
- Cron で定期実行
- GAS API にデータを送信

### データフロー
```
社長の行動・思考
    ↓
3体のエージェントが観察
    ↓
GAS API にスコア記録
    ↓
スプレッドシートに蓄積
    ↓
成長曲線を可視化
```

---

## 📊 評価頻度

### リアルタイム評価
- タスク完了時: Executor が即座に記録
- 重要な判断時: Judge が即座に記録

### 定期評価
- 毎日: Observer が日記を分析（朝6時）
- 毎週: Judge が週次レビュー（日曜夜）
- 毎月: 成長係数を算出
