Deployment Guide

Trinity System v2を本番環境にデプロイするための完全ガイドです。

推定所要時間: 15-20分（v1比で大幅短縮）

前提条件

  • Googleアカウント
  • Node.js 18以上
  • 基本的なターミナル操作スキル

Phase 1: データベース構築

1Googleスプレッドシート作成

  1. Google Sheetsで新規スプレッドシート作成
  2. 名前を trinity-system-v2 に変更
  3. URLからスプレッドシートIDをコピー
https://docs.google.com/spreadsheets/d/[ここがID]/edit

2CSVインポート

trinity-db-v2/ ディレクトリの2つのCSVファイルをインポート：

  • users.csv → usersシート
  • events.csv → eventsシート

インポート手順:

  1. ファイル → インポート → アップロード
  2. 区切り文字: カンマ
  3. 既存データ: 置き換え

確認

  • 2つのシートが作成されている
  • usersシートに1行のデータがある
  • eventsシートにヘッダー行がある

Phase 2: GAS APIデプロイ

1Apps Scriptプロジェクト作成

  1. スプレッドシートを開く
  2. 「拡張機能」→「Apps Script」
  3. 新しいプロジェクトが開く

2コードのコピー

  1. gas-api-v2/Code.gs の内容をコピー
  2. Apps Scriptエディタに貼り付け
  3. 2行目の SPREADSHEET_ID を実際のIDに置き換え
const SPREADSHEET_ID = 'あなたのスプレッドシートID';
  1. 保存（Ctrl+S / Cmd+S）

3Web Appとしてデプロイ

  1. 右上の「デプロイ」→「新しいデプロイ」
  2. 種類: ウェブアプリ
  3. 説明: Trinity System v2 API
  4. 次のユーザーとして実行: 自分
  5. アクセスできるユーザー: 全員
  6. 「デプロイ」をクリック
  7. ウェブアプリのURL をコピー（必ず保存）

動作確認:

ブラウザで以下にアクセス：

https://script.google.com/macros/s/YOUR_ID/exec?path=user&user_id=uuid-001

ユーザー情報がJSON形式で返ってくればOKです。

Phase 3: エージェント設定

1環境変数設定

agents-v2/ ディレクトリで .env ファイルを作成：

cd agents-v2
cp .env.example .env

.env ファイルの内容：

TRINITY_API_URL=https://script.google.com/macros/s/YOUR_ID/exec
USER_ID=uuid-001
WORKSPACE=/root/clawd

Phase 4: 動作確認

エージェント手動実行

cd agents-v2

# Observer実行
node observer.js

# Judge実行
node judge.js

# Executor実行
node executor.js

スプレッドシート確認

  • eventsシートにイベントが記録されている
  • usersシートのスコアが更新されている

Phase 5: Cron設定

定期実行のためにCronジョブを設定：

crontab -e

以下を追加：

0 6 * * * cd /root/clawd/agents-v2 && node observer.js
0 21 * * 0 cd /root/clawd/agents-v2 && node judge.js
0 22 * * * cd /root/clawd/agents-v2 && node executor.js

# Growth Calculator（月次）
0 0 1 * * cd /root/clawd/batch-v2 && node growth-calculator.js

デプロイ完了チェックリスト

  • Googleスプレッドシート作成完了
  • 2つのCSVをインポート完了
  • GAS API デプロイ完了
  • API動作確認完了（ブラウザでアクセス）
  • .env ファイル作成・設定完了
  • エージェント手動実行成功
  • スプレッドシートにデータ記録確認
  • Cronジョブ設定完了

デプロイ完了

すべてのチェックリストが完了したら、Trinity System v2が正常に動作しています。
