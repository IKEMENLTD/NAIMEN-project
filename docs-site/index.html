Trinity - 三位一体

認識力 (Perception)

現実をありのまま見る力を測定。日記分析、認知バイアス検出により、自己欺瞞のない正確な自己認識を評価します。

判断力 (Judgment)

本質を掴み、優先順位を正しくつける力を測定。論理性、一貫性、根本原因思考により、最適な意思決定能力を評価します。

実行力 (Execution)

選択を現実にする力を測定。完遂率、即行動性、継続力により、確実に成果を出す実行能力を評価します。

アーキテクチャ

イベントソーシング

すべての変更をイベントとして記録。現在の状態はイベントから導出され、履歴の改ざんが不可能な設計です。

2シート構成

users（現在の状態）とevents（全イベント履歴）のみ。7シートから2シートへの最適化により、管理が容易で拡張性が高い設計を実現しました。

統一API

3つのエンドポイント（GET /user, GET /events, POST /event）のみ。7エンドポイントから3エンドポイントへの統合により、一貫性のある操作を提供します。
